Built the `/today` page: the latest entry reads full width, with a quiet month calendar and a short list of recent days below it. Entries are one file per day in `jagskverma/today`, and a GitHub Action rebuilds the index on push, so adding a day needs no deploy.

Published [readable](https://github.com/jagskverma/readable), a browser extension that unslops a page: click the toolbar button and the prose comes back as something you can actually read. It rewrites the text with ChatGPT or a local Ollama model. I wrote it while working through the inference course, whose site was full of exactly what it removes.

Finished [session three](https://llminference.xinbetween.com/en/s03/) of that course: the transformer forward pass. Attention, RoPE, and the rest of the block from RMSNorm to SwiGLU, implemented in code rather than described.
