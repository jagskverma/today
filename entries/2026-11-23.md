1. Built the `/today` page. The latest entry spans the full width, with a simple month calendar and a short list of recent days below it. Each day has its own file in `jagskverma/today`. A GitHub Action rebuilds the index on every push, so I can add an entry without deploying the site.

2. Published [readable](https://github.com/jagskverma/readable), a browser extension that makes sloppy prose easier to read. Click the toolbar button to rewrite the page's text with ChatGPT or a local Ollama model. I wrote it because the inference course site was full of the kind of prose it fixes.

3. Finished [session three](https://llminference.xinbetween.com/en/s03/) of that course: the transformer forward pass. The session uses code to show how attention, RoPE, and the rest of the block work, from RMSNorm to SwiGLU.
